# 🌴 GTA VI - Community Sentiment Dashboard 🌴

Un dashboard interactivo desarrollado en Python para analizar y visualizar las reacciones, expectativas y sentimientos de la comunidad frente a los avances de **Grand Theft Auto VI**.

## 📊 Características Principales
El centro de comando está dividido en tres vistas analíticas:
* **Resumen Ejecutivo:** Visión global del impacto, volumen total de interacciones y métricas de polaridad general.
* **Temas y Comparaciones:** Ranking de temáticas más discutidas (ej. gráficos, mapa, precio) y un mapa jerárquico de sentimientos estilo *Vice City Skyline*.
* **Evidencia y Calidad:** Tabla de datos en bruto con filtros de búsqueda interactivos y métricas de validación de la muestra.

## 🛠️ Tecnologías Utilizadas
* **[Streamlit](https://streamlit.io/):** Interfaz web y despliegue del dashboard.
* **[Plotly](https://plotly.com/python/):** Gráficos interactivos con degradados personalizados (Neón/Dark Mode).
* **[Pandas](https://pandas.pydata.org/):** Limpieza, manipulación y estructuración de los datos.
* **Openpyxl:** Motor de lectura para bases de datos cualitativas en Excel.
